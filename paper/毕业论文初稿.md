# 基于地理分组泛化与异构专家融合的县域农业环境数据 PM2.5 浓度预测研究

## 摘要

细颗粒物 PM2.5 是衡量空气污染程度、环境暴露风险与生态健康压力的重要指标。针对县域尺度农业环境表格数据中样本规模中等、地理层级显著、跨区域泛化困难、随机划分易产生地理泄漏等问题，本文围绕 `data.csv` 构建了一套面向表格回归的 PM2.5 预测方法与完整实验流程。本文首先对 2676 条县域样本、31 个省级行政区、338 个城市的数据进行了系统审计，发现随机划分会显著高估性能，因此采用 `GroupKFold(CITY)` 作为主评估协议，同时保留 `RandomKFold` 与 `GroupKFold(PROVINCE)` 作为对照协议。随后，本文在统一特征工程下实现并比较 Ridge、RandomForest、HistGradientBoosting、XGBoost、LightGBM、CatBoost、TabPFN 等强基线。进一步地，本文提出 GeoPFNMix 框架，通过“全局专家 + 地理层级残差校正 + 异构先验专家 + 低容量 stacking”来同时处理非线性关系、地理系统偏差和小样本泛化问题。在框架基础上，本文进一步发展出三个关键子配置：面向稳定交付的 `GeoPFNMix-Lite`、面向更强全局专家的 `GeoPFNMix-CatBoost`、以及在获得 TabPFN 授权后形成的 `GeoPFNMix-Lite-TabPFN` 与 `GeoPFNMix-CatBoost-TabPFN`。实验结果表明，TabPFN 已成为当前环境下最强单模型，在主协议 `GroupKFold(CITY)` 下取得 `RMSE=12.5009`、`MAE=9.6614`、`R²=0.1415`；在此基础上，`GeoPFNMix-Lite-TabPFN` 进一步取得全局最优结果 `RMSE=12.4848`、`MAE=9.4729`、`R²=0.1442`，相较单模型 TabPFN 的 RMSE 再下降 `0.13%`，MAE 再下降 `1.95%`，且 Wilcoxon 配对检验表明改进具有统计显著性（`p=9.89e-06`）。相比之下，`GeoPFNMix-CatBoost` 的提出则验证了“更强全局专家”这一设计方向本身具有有效性：在 LightGBM 先验下，`GeoPFNMix-CatBoost` 相对 CatBoost 单模型实现了 `0.13%~0.93%` 量级的误差改进；在引入 TabPFN 先验后，`GeoPFNMix-CatBoost-TabPFN` 进一步提升到 `RMSE=12.5035`、`MAE=9.5188`。最后，本文通过协议热力图、消融指标图、目标区间误差图、省级误差图与最佳专家 SHAP 图，对模型性能来源与局限进行了系统分析。研究表明，污染前体物及其组合、风速与区域层级信息共同决定了 PM2.5 预测效果，而地理分组评估、低容量融合和可插拔先验专家是本课题取得稳定结果的关键。本文工作为面向地理异质性的小中样本农业环境表格数据 PM2.5 预测提供了一条可复现、可解释、具备毕业设计完整性的技术路线。

**关键词**：PM2.5 预测；地理泛化；表格回归；GeoPFNMix；GeoPFNMix-Lite；TabPFN；模型融合；SHAP

## 1 绪论

### 1.1 研究背景与现实意义

PM2.5 作为典型的大气细颗粒污染物，能够通过呼吸系统暴露、区域灰霾形成、生态环境退化和农业生产风险等多个路径影响社会与自然系统。对县域尺度而言，PM2.5 不仅反映区域大气环境质量，也折射出农业活动、污染排放与气象条件之间复杂的相互作用关系。因此，在县域粒度上建立可信的 PM2.5 预测模型，既具有环境信息化与数据智能的研究价值，也具有一定的应用意义。

与城市空气质量监测中常见的时序预测任务不同，本文面对的是一个静态截面的县域农业环境数据集。该数据集同时包含 `PROVINCE`、`CITY`、`COUNTY` 等地理层级变量，以及 `AET`、`ppt`、`tem`、`wind`、`NOX`、`SO2`、`fertilzier`、`manure` 等农业环境相关变量。换句话说，本文不是在解决“给定历史时间序列预测未来某一天 PM2.5”的问题，而是在解决“给定一个县域的农业、污染与气象特征，能否预测其 PM2.5 水平，并在未见过的城市里仍保持一定泛化能力”的问题。

这一任务有三个显著特点。第一，样本量并不大，总样本仅 2676 条，属于典型的中小样本表格学习场景。第二，数据具有明显的地理层级结构，若采用普通随机划分，很容易让同一地区的统计规律泄漏到测试集，得到虚高结论。第三，输入特征既包含农业投入与污染前体物，也包含气象背景变量和行政区类别变量，关系明显非线性且伴随交互作用。因此，如何在严格协议下获得可信结果，并把方法设计、实验分析、图表资产和论文叙述组织为一个完整毕设故事，是本文的核心任务。

### 1.2 问题提出

从项目推进过程来看，最初的问题并不是“用哪个模型能把分数做到最高”，而是“在不依赖地理泄漏的前提下，究竟应该怎样构造一个既合理又可交付的模型体系”。如果只从单模型性能出发，随机划分下的 CatBoost、XGBoost 甚至 TabPFN 都能取得相对不错的结果；但一旦转到 `GroupKFold(CITY)` 或 `GroupKFold(PROVINCE)`，误差会明显增大。这说明在本课题中，评估协议的严谨性本身就是研究问题的一部分。

进一步地，即便在确定了严格协议之后，项目仍然面临三个关键困难。其一，县域级别的 `COUNTY` 字段几乎接近近唯一标识，如果不加控制地纳入模型，会让模型过度记忆地区身份。其二，小样本和强分组交叉验证会使高容量元学习器很容易在 OOF 元特征上过拟合。其三，尽管树模型在表格任务上表现强势，但单一树模型未必能够同时兼顾全局非线性关系、地理系统偏差和小样本先验知识。

正是在这个背景下，本文逐步提出并发展了 GeoPFNMix 家族。GeoPFNMix 不是一个凭空提出的大而全模型名称，而是整个项目围绕“地理泛化 + 异构专家 + 可复现执行”逐步演化出来的方法集合。GeoPFNMix 是总框架，GeoPFNMix-Lite 是面向稳定交付的简化版本，GeoPFNMix-CatBoost 是面向更强全局专家的增强版本，而在获得 TabPFN 授权后，又自然延伸出 Lite-TabPFN 和 CatBoost-TabPFN 这样的二阶段扩展版本。本文将清楚交代这些模型的提出动机、设计目标、适用场景和实验意义。

### 1.3 研究目标与研究问题

围绕上述背景，本文的研究目标可以表述为：

1. 在县域农业环境静态表格数据上建立一个可复现、可解释、在跨城市泛化协议下具有稳定性能的 PM2.5 回归模型。
2. 明确量化随机划分导致的地理泄漏问题，并将其转化为论文中的一个重要研究发现。
3. 设计并验证一个兼顾强基线、地理残差校正、异构先验和低容量融合的统一框架。
4. 通过消融实验回答三个具体问题：GeoPFNMix 是否有效、GeoPFNMix-Lite 为什么需要、GeoPFNMix-CatBoost 又为什么值得提出。
5. 在获得 TabPFN 授权后，进一步验证 foundation model 先验能否真正提升已有融合框架，而不是停留在概念引用层面。

对应地，本文要回答的研究问题包括：

- 为什么 `GroupKFold(CITY)` 应该成为主协议？
- `COUNTY` 为什么不适合作为主类别特征？
- GeoPFNMix 为什么要分成全局专家、地理残差分支和先验专家三部分？
- GeoPFNMix-Lite 与 GeoPFNMix-CatBoost 分别解决什么问题？
- 在当前数据和环境下，TabPFN 是更适合做单模型，还是更适合做先验专家？

### 1.4 主要贡献

本文的主要贡献可以归纳为以下六点：

1. 在数据层面，系统审计了县域农业环境数据的结构特征、样本分布与泄漏风险，确立了以 `GroupKFold(CITY)` 为核心的评估协议。
2. 在方法层面，提出 GeoPFNMix 总体框架，并明确区分 `GeoPFNMix`、`GeoPFNMix-Lite`、`GeoPFNMix-CatBoost` 的提出动机与设计目标。
3. 在实验层面，构建了覆盖 Ridge、RF、HGBT、XGBoost、LightGBM、CatBoost、TabPFN 的统一强基线体系。
4. 在扩展层面，解决了 TabPFN 的无人值守认证问题，并新增 `GeoPFNMix-Lite-TabPFN` 和 `GeoPFNMix-CatBoost-TabPFN` 作为 PFN 先验增强对照。
5. 在分析层面，新增协议热力图、消融指标图、目标区间误差图、省级误差图和最佳专家 SHAP 图，使论文图表资产更加完整。
6. 在工程层面，同步更新 README、实验日志和项目日记，保证代码、结果、图表与论文之间的一致性与可追溯性。

## 2 相关工作

### 2.1 PM2.5 预测研究

PM2.5 预测研究长期围绕排放源、气象调制、空间异质性和时间动态等因素展开。在城市尺度或区域尺度的研究中，时间序列模型、随机森林、梯度提升树、神经网络乃至时空图模型都被广泛使用。然而，对于县域尺度、静态表格、特征维度有限且缺少时间轴的任务，这些研究结论不能简单照搬。因为这里的问题不再是“短期动态演化”，而更接近“跨区域环境风险回归建模”。

既有研究普遍显示，污染前体物和气象条件在 PM2.5 形成中具有核心作用，而区域背景与空间差异会显著改变这些变量的作用方式。例如，同样的 `NOX` 水平，在不同风速、不同省份和不同城市背景下，对 PM2.5 的贡献可能并不一致。本文虽然没有经纬度或邻接图，但通过省、市、县三级行政标签和若干农业环境变量，仍然具备了构建“区域异质性 + 非线性关系”模型的基础。

### 2.2 表格数据学习研究

表格学习研究一个长期结论是：在中小样本任务中，强树模型依然具有极强的竞争力。Gorishniy 等人的研究系统比较了传统树模型和深度表格模型，指出不存在在所有任务上绝对占优的方法，树模型仍应被视为严肃基线。这一判断直接影响了本文的技术路线，即不把深模型作为先验正确答案，而是先建立稳健强基线，再在此基础上做结构化改进。

TabPFN 的出现为小样本表格任务提供了新的思路。它并不是传统意义上的“再训练一个深度网络”，而是通过预训练先验来提升下游推理能力。这种“先验专家”的思想恰恰适合与本文的 GeoPFNMix 框架结合：GeoPFNMix 需要一个与树模型不同归纳偏置的第二专家，而 TabPFN 正好具备这样的互补特征。项目早期受限于授权流程，TabPFN 只能被写入相关工作与代码接口；在本轮项目迭代中，TabPFN 已经能够正式进入结果表，从而让论文的 foundation model 叙事真正落地。

### 2.3 地理分组泛化与混合效应思想

虽然本文并未直接使用严格的统计混合效应模型，但 GeoPFNMix 中的地理残差分支明显借鉴了“分层偏置校正”的思想。省级和城市级并不是普通类别变量，它们在本任务中更接近“区域背景”的代理。因此，与其让单一树模型完全隐式学习所有地理结构，不如显式构造一个残差校正模块，把这部分系统偏差单独处理。

更重要的是，本文将评估协议也视作建模的一部分。因为一旦评估协议不能真实反映跨城市泛化，那么再高的结果也未必有研究说服力。正因如此，GeoPFNMix 家族从一开始就不是为了在随机划分上追求最优，而是为了在地理分组协议下获得更可信、更有解释性的改进。

### 2.4 本文工作的定位

综合来看，本文工作的定位不是提出一个完全脱离应用背景的“新模型名词”，而是围绕真实的地理泛化问题，把强基线、地理层级意识、小样本先验和工程可交付性结合起来。本文的创新更接近“结构化研究工程创新”，其价值在于：

- 不是简单调用现成模型，而是形成了以 GeoPFNMix 为主线的方法演进；
- 不是只报一个最佳分数，而是给出协议差异、消融、显著性和解释分析；
- 不是只把 foundation model 写进综述，而是最终把 TabPFN 正式拉进了实验对照与融合框架。

### 3.3 为什么不把 COUNTY 作为主类别特征

在县域级数据上，最容易犯的错误之一就是把 `COUNTY` 直接当作普通类别变量送入模型。这样做短期内往往会提高随机划分成绩，因为模型学到的是地区记忆而不是可迁移规律。本文之所以在正式建模中移除 `COUNTY` 的主类别编码地位，是基于以下考虑。

首先，`COUNTY` 的高基数和近唯一性质，会让模型通过“识别这个县以前出现过”来降低误差，这显然不符合跨城市泛化的目标。其次，在 `GroupKFold(CITY)` 中，城市级别已经是核心分组单位，如果再把 `COUNTY` 明确编码，实际上会进一步加强地理标识性，从而使模型更依赖局部标签。再次，毕业设计不仅要有分数，还要有研究解释性；如果一个模型大量依赖县级近唯一标识，即使分数看起来漂亮，论文也很难有说服力。

因此，本文将 `COUNTY` 保留为原始数据中的元信息，但不作为主要类别特征进入统一特征工程。最终进入模型的主类别特征只有 `PROVINCE` 与 `CITY`。

### 3.4 问题定义

设第 $i$ 个县域样本的输入特征为 $x_i$，目标值为 $y_i$，则本文研究的问题可以形式化为一个监督回归任务：

$$
\hat{y}_i = f(x_i),
$$

其中 $\hat{y}_i$ 表示模型预测的 PM2.5 浓度。本文的重点不在于构造一个任意复杂的函数 $f$，而在于如何使 $f$ 在地理分组协议下仍然具备稳定泛化能力。

### 3.5 评估协议与指标

为量化地理泄漏并严格评价模型，本文设置三套协议：

1. `RandomKFold(5)`：作为理想化随机划分对照；
2. `GroupKFold(5, CITY)`：作为主协议，强调跨城市泛化；
3. `GroupKFold(5, PROVINCE)`：作为更严格的跨省泛化协议。

评价指标为 RMSE、MAE 和 R²。其中 RMSE 用于衡量整体误差量级，MAE 用于衡量平均绝对偏差，R² 用于描述解释方差程度。论文主结论以 `GroupKFold(CITY)` 为准，而随机划分结果只作为“地理泄漏对照”，不作为主要结论依据。

## 4 方法

### 4.1 统一特征工程

为了保证不同模型之间的公平比较，本文构建了统一的特征工程模块。这个模块不是随意增加特征数量，而是围绕污染机理、农业环境背景和区域相对差异进行设计。其具体过程包括：

1. 对所有数值变量做 `1%` 和 `99%` 分位裁剪，以减弱极端值对树模型分裂的干扰；
2. 对 `ppt`、`NOX`、`SO2`、`fertilzier`、`manure` 等偏态变量做 `log1p` 变换，减小长尾分布影响；
3. 构造污染协同项，如 `NOX_plus_SO2`、`NOX_div_SO2`；
4. 构造农业投入与气象交互项，如 `fertilzier_x_wind`、`manure_x_ppt`、`SO2_x_wind`、`NOX_x_tem`；
5. 构造省内相对强度特征，如 `province_z_NOX`、`province_z_ppt` 等，以刻画样本相对本省背景的偏离程度；
6. 构造样本支撑度特征，如 `province_sample_count`、`city_sample_count`、`is_low_support_city`。

这种设计有两个优点。其一，它尽量让特征仍然保有可解释性，而不是完全依赖黑箱自动组合。其二，它为后续的残差校正与元学习器提供了稳定的输入，使 GeoPFNMix 的多路专家输出拥有更丰富但不过度冗余的信息基础。

### 4.2 强基线模型体系

本文设置的强基线包括：

- Ridge
- RandomForest
- HistGradientBoosting
- XGBoost
- LightGBM
- CatBoost
- TabPFN

这些模型覆盖了线性模型、Bagging 树、Boosting 树和 foundation model 风格先验模型。之所以要保留如此广覆盖的基线，不只是为了“让论文看起来完整”，更重要的是为 GeoPFNMix 的不同设计选择提供参照。例如，GeoPFNMix-Lite 之所以使用 RF 作为全局专家，是因为在早期实验中 RF 的跨城市稳定性较好；GeoPFNMix-CatBoost 之所以被提出，是因为后来发现 CatBoost 在类别信息和非线性关系处理上更强，值得作为更高质量的全局专家骨干。

### 4.3 GeoPFNMix 的提出：动机、目标与总体框架

#### 4.3.1 提出动机

GeoPFNMix 的提出，并不是简单地把几个模型堆在一起，而是源于对任务难点的逐层拆解。本文认为，仅依赖单一树模型存在三个局限：

1. 单模型虽然可以学习非线性关系，但难以明确区分“全局规律”和“地区系统偏差”；
2. 对低样本地区来说，单模型很难获得额外先验支持；
3. 如果完全把复杂性交给高容量元学习器，又会在小样本场景下迅速过拟合。

因此，GeoPFNMix 试图把问题拆分为三个相互配合的部分：由全局专家负责总体非线性关系，由地理残差分支显式处理系统性区域偏差，再由异构先验专家提供与全局专家不同的归纳偏置，最后交给低容量 stacking 做有限度的信息融合。

#### 4.3.2 设计目标

GeoPFNMix 的设计目标可以概括为五点。

第一，**跨城市泛化优先**。模型必须围绕 `GroupKFold(CITY)` 设计，而不是围绕随机划分高分设计。第二，**模块职责明确**。全局专家、残差分支和先验专家各自承担不同功能，而不是所有能力都压在一个黑箱模型里。第三，**低容量融合**。元学习器要尽量简单，以防止 OOF 元特征过拟合。第四，**支持无人值守执行**。即使没有交互式界面，方法也要尽量能够落地运行。第五，**可插拔先验专家**。当前先验可以是 LightGBM，也可以在条件允许时切换为 TabPFN，而不破坏整体框架。

#### 4.3.3 总体形式

GeoPFNMix 的总体预测函数可写为：

$$
\hat{y} = g\big(\hat{y}_{global}, \hat{y}_{global} + \hat{r}_{geo}, \hat{y}_{prior}, m(x)\big),
$$

其中：

- $\hat{y}_{global}$ 为全局专家预测；
- $\hat{r}_{geo}$ 为地理残差校正；
- $\hat{y}_{prior}$ 为先验专家预测；
- $m(x)$ 为元特征，如样本支撑度和专家分歧。

这里的关键不在于公式本身，而在于设计思想：GeoPFNMix 允许我们把“学习总体关系”“处理区域偏差”“引入先验知识”这三件事拆开，再用一个低自由度的融合器把它们重新组合。

### 4.4 地理层级残差校正

GeoPFNMix 的第二个核心模块是地理层级残差校正。给定全局专家预测 $\hat{y}_{global}$，定义残差：

$$
r_i = y_i - \hat{y}_{global,i}.
$$

然后对残差建立省级和城市级的经验贝叶斯式校正：

$$
\hat{r}_i = b_0 + b_{province(i)} + b_{city(i)}.
$$

其中 $b_0$ 表示全局残差均值，$b_{province(i)}$ 表示省级收缩效应，$b_{city(i)}$ 表示城市级收缩效应。为了避免小样本城市被噪声主导，本文并不直接使用原始局部均值，而是采用“样本数 / (样本数 + 平滑项)”的形式进行收缩。这使得样本数多的地区更接近局部经验，样本数少的地区更接近全局或上级平均。

这一模块的研究意义在于，它把“区域背景偏差”从主预测器中显式分离出来，使模型结构更符合环境类问题的直觉。对于毕业论文而言，这种显式结构化设计也比“全交给一个黑箱模型自己学”更便于解释和论证。

### 4.5 GeoPFNMix-Lite 的提出

#### 4.5.1 提出动机

GeoPFNMix 的完整框架虽然概念上完整，但在项目早期实验中暴露出一个明显问题：当样本规模不大、OOF 元特征有限时，复杂度每增加一步，过拟合风险也会随之上升。尤其是在早期使用更高容量的元学习器或保留过多后处理分支时，结果并没有稳定提升。为了得到一个更适合本科毕设交付、结果稳定、结构简洁且便于解释的版本，本文提出 GeoPFNMix-Lite。

GeoPFNMix-Lite 的本质不是“把模型做弱”，而是“保留真正稳定有效的部分，把不稳定模块从主交付版本中剥离出来”。其初始版本采用 `RF` 作为全局专家，`LightGBM` 作为异构先验专家，并仅保留线性 stacking，而不使用地理残差分支。这样设计的好处在于：结构短、参数少、运行稳定、解释清晰，而且仍然体现了“异构专家融合”的方法创新。

#### 4.5.2 设计目标

GeoPFNMix-Lite 的设计目标主要有三点。第一，保持 GeoPFNMix 的核心思想，即“不要只依赖单一模型，而要利用异构专家的互补性”。第二，控制元学习器复杂度，使其更适合中小样本场景。第三，保证方法在无头环境下可以稳定执行，即便 TabPFN 暂时不可用，也可以用 LightGBM 先验维持完整流程。

#### 4.5.3 结构定义

GeoPFNMix-Lite 的初始定义为：

> `GeoPFNMix-Lite = RF 全局专家 + LightGBM 先验专家 + 线性 stacking`

在获得 TabPFN 授权后，本文进一步提出：

> `GeoPFNMix-Lite-TabPFN = RF 全局专家 + TabPFN 先验专家 + 线性 stacking`

可以看到，Lite 本身并不是固定绑定某一个先验，而是一种“轻量融合架构”。因此，LightGBM 版本与 TabPFN 版本应理解为同一家族下的两个阶段性实现：前者解决“先把框架跑通”，后者解决“当更强先验可用时，框架是否还能继续受益”。

### 4.6 GeoPFNMix-CatBoost 的提出

#### 4.6.1 提出动机

随着实验推进，项目发现单模型 CatBoost 在当前数据上的表现逐渐逼近甚至超过 RF。这提示我们，GeoPFNMix 框架的上限可能并不取决于“残差分支是否存在”，而更大程度上取决于“全局专家本身是否足够强”。于是，本文提出 GeoPFNMix-CatBoost：不改变 GeoPFNMix 的框架思想，只把全局专家从 RF 替换为 CatBoost。

提出这一版本的直接动机在于，CatBoost 对类别变量的处理更加自然，对 `PROVINCE`、`CITY` 这类地理类别特征通常更友好；同时，它在中小样本表格任务上的稳定性也较高。因此，若 GeoPFNMix 的瓶颈部分来自全局专家能力不足，那么换用 CatBoost 可能比单纯增删残差分支更有效。

#### 4.6.2 设计目标

GeoPFNMix-CatBoost 的设计目标是：

1. 在不破坏 GeoPFNMix 框架整体解释性的前提下，提高全局专家质量；
2. 观察“更强全局专家 + 地理残差 + 异构先验”的组合是否优于 RF 系列版本；
3. 为论文提供一个更清楚的方法演化路径：GeoPFNMix 是框架，GeoPFNMix-Lite 是轻量化子配置，GeoPFNMix-CatBoost 是更强全局专家方向的扩展。

#### 4.6.3 结构定义

GeoPFNMix-CatBoost 的初始定义为：

> `GeoPFNMix-CatBoost = CatBoost 全局专家 + 地理残差校正 + LightGBM 先验专家 + 线性 stacking`

在获得 TabPFN 授权后，本文进一步构造：

> `GeoPFNMix-CatBoost-TabPFN = CatBoost 全局专家 + 地理残差校正 + TabPFN 先验专家 + 线性 stacking`

这样，GeoPFNMix 家族形成了一个清晰的模型谱系：总框架、轻量子配置、强化全局专家版本，以及以 TabPFN 为先验的增强版本。

### 4.7 先验专家为什么重要：从 LightGBM 到 TabPFN

GeoPFNMix 之所以引入“先验专家”，其核心逻辑在于：如果全局专家已经是一个强树模型，那么单纯再加一个非常相似的树模型未必能带来真正互补的信息。理想的先验专家，应该拥有与全局专家不同的归纳偏置。LightGBM 在项目早期承担了这样一个可执行、开放、稳定的先验角色；而 TabPFN 则在 token 和授权问题解决后，成为更自然的 PFN 风格先验选择。

将 TabPFN 作为先验专家的意义至少有三点。第一，它比传统树模型更贴近“小样本先验”的原始设想。第二，它使 GeoPFNMix 这个名称中的 PFN 部分不再只是概念指代，而真正落入可执行实验。第三，它为论文讨论提供了一个更完整的演化链条：从 LightGBM 先验的可执行版本，到 TabPFN 先验的增强版本，方法故事更加完整，也更有研究意味。

### 4.8 训练与推理流程

将 GeoPFNMix 家族的训练过程总结为算法流程，可概括为以下步骤：

1. 读取原始数据，去掉 `OBJECTID_1`，保留 `PROVINCE` 和 `CITY` 作为主类别特征；
2. 进行统一特征工程，生成裁剪、对数、交互、分省相对强度与支撑度特征；
3. 训练全局专家，得到总体非线性预测；
4. 若启用残差分支，则根据训练集残差构建省级和城市级收缩校正；
5. 训练异构先验专家，得到第二路预测；
6. 构造元特征，包括全局预测、残差校正预测、先验预测、专家差值和支撑度等；
7. 使用低容量线性 stacking 在 OOF 元特征上训练融合器；
8. 在测试或验证样本上按同一流程生成最终预测。

这一流程的优点在于，虽然模型是融合模型，但其每个组成部分都有清楚职责，既便于调试，也便于论文解释。

第一，**GeoPFNMix 作为总框架是成立的**。无论是 Lite 版本、完整版本、CatBoost 版本，还是 TabPFN 先验版本，至少其中的若干变体都能优于对应的基础模型，而且这种增益在不同骨干和不同先验上都具有一致方向。

第二，**GeoPFNMix-Lite 的提出是必要的**。如果没有 Lite 版本，就无法在结构上回答“小样本下是否应该保留全部分支”这个问题。实验表明，在 LightGBM 先验下，Lite 明显优于完整 RF 版 GeoPFNMix，这说明简化并不是“退化”，而是在特定数据规模下对泛化风险的主动控制。

第三，**GeoPFNMix-CatBoost 的提出是有意义的**。虽然最终最优结果出现在 Lite-TabPFN 上，但 GeoPFNMix-CatBoost 证明了“更强全局专家”这一设计方向本身有效。在 LightGBM 先验下，它已能优于 CatBoost 单模型；在 TabPFN 先验下，它又进一步接近最优结果。这说明 GeoPFNMix-CatBoost 不是多余分支，而是整个家族向更强骨干演化的自然一步。

第四，**完整 GeoPFNMix 在更强先验下依然值得保留为对照**。本轮新增的 `GeoPFNMix-TabPFN` 明显优于 LightGBM 先验的完整版本，说明残差分支并不是“完全无效”，而是它的有效性依赖于先验质量与整体自由度的配合方式。也正因为如此，论文才能更有说服力地指出：问题不在于“残差分支有没有意义”，而在于“在当前样本规模下，它是否值得与更强先验同时开启并长期作为最终方案保留”。

图 6 给出了主协议下的 RMSE 比较。可以直观看到，Lite-TabPFN 与 CatBoost-TabPFN 位于最优区间，而 RF 系列不带先验的版本整体偏弱。

![图 6 GeoPFNMix 家族 RMSE 对比](../artifacts/figures/group_city_model_comparison.png)

图 7 进一步展示了 RMSE 和 MAE 两个指标上的消融差异。该图能够说明：有些模型虽然 RMSE 不占优，但 MAE 有明显提升，这意味着它们在“整体平均误差控制”上更好，而不是只在少数样本上受益。

![图 7 GeoPFNMix 家族消融指标图](../artifacts/figures/geopfnmix_ablation_metrics.png)

### 6.3 为什么 GeoPFNMix-Lite 值得单独强调

GeoPFNMix-Lite 在本文中占据特殊位置。原因不只是它曾经是项目早期最优版本，更重要的是它代表了一种方法论判断：在小样本、强分组、元特征有限的情况下，适度减法比盲目加法更重要。

从结果看，LightGBM 先验的 GeoPFNMix-Lite 相比 RF 单模型在 RMSE 上取得 `0.47%` 的改进，在 MAE 上取得更明显的下降；而完整 RF 版 GeoPFNMix 则没有继续提升。这说明 Lite 不是为了“好听”而起的名字，而是一个经过实验筛选得到的结构化简化版本。

更进一步，在引入 TabPFN 先验后，Lite 结构表现出更强的可扩展性：`GeoPFNMix-Lite-TabPFN` 相比原始 `GeoPFNMix-Lite`，RMSE 再下降 `1.93%`，MAE 再下降 `3.67%`，且配对检验 `p=2.77e-15`，改进非常稳定。换言之，Lite 的价值不只是“轻量化”，还在于它为更强先验的引入留下了低风险、低干扰的接口。

更重要的是，Lite-TabPFN 与 Full-TabPFN 的直接比较也给出了非常清楚的信号。`GeoPFNMix-Lite-TabPFN` 在 RMSE 与 MAE 上都优于 `GeoPFNMix-TabPFN`，且配对检验 `p=3.73e-03`。这意味着当先验已经足够强时，继续叠加更复杂的残差分支未必带来额外收益，反而可能增加结构方差。这个结论对于本科论文很关键，因为它把“Lite 为什么必要”从经验观察提升为有对照支撑的研究判断。

### 6.4 为什么 GeoPFNMix-CatBoost 值得提出

GeoPFNMix-CatBoost 的重要性体现在“方法演化逻辑”而不仅仅是“最终最好”。它回答的是另一个问题：当单模型基线中出现更强的类别友好型模型时，是否应当继续坚持原来的全局专家，还是应该把更强的模型吸收到框架中。

实验给出的答案是：值得吸收。`GeoPFNMix-CatBoost` 在 LightGBM 先验条件下，相比单模型 CatBoost 的 RMSE 降低约 `0.93%`，MAE 降低 `3.76%`，且 `p=2.55e-07`。这说明“强全局专家 + 轻量融合”的方向是成立的。虽然当 TabPFN 先验真正加入后，`GeoPFNMix-Lite-TabPFN` 略微反超了 `GeoPFNMix-CatBoost-TabPFN`，但这并不削弱 GeoPFNMix-CatBoost 的研究价值。相反，它帮助论文更清楚地说明：GeoPFNMix 不是一个单点模型，而是一个可以沿着“先验增强”和“骨干增强”两条线不断演化的方法家族。

### 6.5 TabPFN 作为先验专家，值不值得？

这是本轮项目迭代中最重要的新问题之一。基线结果表明，TabPFN 已经是最强单模型；那么继续把 TabPFN 放进融合框架，会不会只是增加复杂度而没有收益？

实验结果显示，答案是“值得，但收益结构不同”。对于 Lite 结构，TabPFN 先验的价值非常明确：`GeoPFNMix-Lite-TabPFN` 不仅优于 LightGBM 先验版本，也优于单模型 TabPFN，本质上说明 RF 全局专家和 TabPFN 先验之间确实存在互补关系。相比单模型 TabPFN，它的 RMSE 再下降 `0.13%`，MAE 再下降 `1.95%`，配对检验 `p=9.89e-06`。这说明融合收益虽然不算巨大，但是真实存在且统计显著。

对于完整 GeoPFNMix 结构，TabPFN 先验同样有效：`GeoPFNMix-TabPFN` 相比 `GeoPFNMix` 的 RMSE 明显下降，配对检验 `p=4.78e-15`。这说明“PFN 先验增强”并不是只对 Lite 生效，而是对整个 GeoPFNMix 家族都成立。只是从最终收益效率看，Full-TabPFN 仍略逊于 Lite-TabPFN，这再次提示我们应当把“是否继续堆叠结构”视为一个需要实验约束的问题，而不是默认越复杂越先进。

对于 CatBoost 结构，TabPFN 先验依然有增益，但增益幅度更小：`GeoPFNMix-CatBoost-TabPFN` 相比 `GeoPFNMix-CatBoost` 的 RMSE 再下降 `0.13%`，MAE 下降 `1.97%`，`p=4.09e-08`。然而，相比单模型 TabPFN，它并没有在 RMSE 上明显超越 Lite-TabPFN。这表明 TabPFN 更适合作为 Lite 架构中的先验增强，而不一定必须与更复杂的 CatBoost + 残差组合绑定才能发挥最大价值。

这一结果对论文叙事非常重要。因为它让我们能够明确写出：TabPFN 在本课题中不是“只作为单模型胜出”，也不是“放进融合框架就一定统治一切”，而是在 Lite 结构中表现出最好的收益效率与模型协同性。这种结论比单纯宣称“用了前沿模型所以更好”更有说服力。

## 7 讨论

### 7.1 GeoPFNMix、GeoPFNMix-Lite 与 GeoPFNMix-CatBoost 的关系

在论文叙事上，这三个名称并不是并列孤立的模型，而是同一个研究过程中的三个关键节点。

GeoPFNMix 是总框架，它代表项目对问题的完整分解：全局专家负责总体规律，残差分支负责区域系统偏差，先验专家负责异构归纳偏置，stacking 负责有限度融合。它的价值在于建立了研究视角和结构语言，使后续所有简化或增强版本都可以围绕这一框架展开。

GeoPFNMix-Lite 是第一个关键子配置。它的提出意味着项目意识到：在中小样本和强分组交叉验证下，复杂并不天然等于更好，保持结构轻量、控制方差、增强可复现性同样是研究设计的一部分。Lite 的出现，使项目不再是“越复杂越像创新”，而是转向“经过筛选的有效创新”。

GeoPFNMix-CatBoost 则代表第二条演化路线：当全局专家变强时，框架上限是否随之提高。它证明了 GeoPFNMix 不是只对 RF 有效，而是具有更一般的结构意义。即便最终最优结果出现在 Lite-TabPFN，上述结论依然成立，因为 CatBoost 版本帮助我们明确看到了“增强骨干”和“增强先验”是两条彼此独立但都值得探索的方向。

### 7.2 为什么最终最优结果落在 GeoPFNMix-Lite-TabPFN

从当前实验结果看，`GeoPFNMix-Lite-TabPFN` 在 RMSE、MAE 和 R² 上都处于最优区间。这一现象值得深入解释。本文认为，原因主要有三点。

第一，Lite 架构的低容量特性更适合和 TabPFN 搭配。TabPFN 自身已经带有较强先验，如果再把它叠加到更复杂的残差 + CatBoost 框架中，虽然仍有增益，但未必比更轻量的 Lite 结构更高效。第二，RF 作为全局专家与 TabPFN 之间具有更明显的归纳偏置互补。第三，Lite 的元学习器负担更小，因此更容易把 TabPFN 带来的补充信息稳定吸收，而不是把额外自由度浪费在拟合噪声上。

换言之，Lite-TabPFN 的胜出并不意味着 GeoPFNMix-CatBoost 失败，而是说明在当前数据规模与协议下，“轻量结构 + 强先验”比“更强骨干 + 更复杂组合”更适合成为最终交付模型。

### 7.3 本研究的局限

尽管本文已经完成了从数据审计、基线、创新模型、TabPFN 对照、显著性检验到图表资产的完整链条，但仍存在若干局限。

首先，数据仍然是静态表格，而不是时间序列或时空序列，因此无法描述污染传播和季节变化。其次，本文缺少经纬度、地形、土地利用、交通、产业结构、遥感 AOD 等更丰富的空间特征，这限制了模型上限。再次，虽然 TabPFN 已经被纳入，但更大规模的结构化 foundation model 如 LimiX 仍未形成可执行对照。最后，当前解释性主要聚焦最佳全局专家，而不是对整个融合系统做统一解释。

### 7.4 对毕业设计完整性的意义

从本科毕业设计的角度看，本文的价值不只在于最后的分数，而在于研究组织的完整性。项目已经覆盖数据理解、协议设计、强基线、创新模型、方法演进、显著性检验、误差分析、SHAP、日志记录和论文撰写等主要环节。相比单纯“跑一个模型然后报结果”的浅层课题，这种完整链条更能体现研究意识与工程能力。

更重要的是，GeoPFNMix 家族提供了一个很适合答辩阐述的故事结构：先指出随机划分会虚高，再解释为什么提出 GeoPFNMix；然后说明为什么需要 Lite 来控制复杂度，为什么又提出 CatBoost 版本来增强骨干；最后在获得 TabPFN 授权后进一步补上 PFN 先验的对照与扩展。这样的叙事既有逻辑推进，也有实验支持，能够让论文更像“做过完整研究”而不是“临时拼接材料”。

### 7.5 后续工作

后续最值得继续推进的方向包括：

1. 引入更严格的空间泛化协议，如 leave-one-province-out、空间块交叉验证等；
2. 增加不确定性估计，使模型不仅输出点预测，还能给出置信区间；
3. 引入外部空间特征，特别是经纬度、路网、土地利用、人口密度与遥感产品；
4. 进一步研究 TabPFN 与更复杂融合结构之间的适配关系；
5. 设计一个轻量的预测演示页面，用于答辩展示和交互解释。

## 8 结论

本文围绕县域农业环境静态表格数据上的 PM2.5 回归预测任务，构建了一条完整的毕业设计研究路线。通过系统的数据审计与协议比较，本文明确指出随机划分会显著高估性能，并确立 `GroupKFold(CITY)` 作为主评估协议。在统一特征工程下，本文构建了覆盖线性模型、树模型与 foundation model 的强基线体系，进一步把 TabPFN 正式纳入结果表，证明其已成为当前环境下的最强单模型。

在方法层面，本文提出 GeoPFNMix 总框架，并进一步发展出 `GeoPFNMix-Lite` 与 `GeoPFNMix-CatBoost` 两条关键演化路线。前者体现了“轻量化、稳健化、控制方差”的设计理念，后者体现了“更强全局专家”的增强思路。在获得 TabPFN 授权后，本文又进一步构造了 `GeoPFNMix-Lite-TabPFN` 与 `GeoPFNMix-CatBoost-TabPFN`，从而使 PFN 先验真正进入可执行实验。

实验表明，当前最佳单模型为 TabPFN，而当前最佳融合模型为 `GeoPFNMix-Lite-TabPFN`。这一结果说明，对于县域 PM2.5 这类小中样本、强地理异质性的表格任务，异构先验与轻量融合的结合能够在严格协议下获得真实、稳定且统计显著的改进。同时，GeoPFNMix-CatBoost 的提出也证明了增强全局专家这条路线本身具有研究价值。总体而言，本文不仅完成了一个可复现、可解释、可交付的毕业设计项目，也为后续继续扩展到更丰富空间特征、更强 foundation model 和更严格空间泛化协议打下了基础。

## 附录 A：GeoPFNMix 家族命名与演化说明

为了避免论文阅读者误解“这些模型名字只是临时堆出来的”，本文在附录中进一步说明命名逻辑。`GeoPFNMix` 中的 `Geo` 指向地理层级意识，`PFN` 指向先验专家方向，`Mix` 指向异构融合。这个名称从一开始就是一个框架性名称，而不是单个不可变模型。

在此框架下，`GeoPFNMix-Lite` 表示对完整框架的轻量化裁剪，核心在于保留异构融合、删减不稳定模块，因此它既是一个模型，也是一种研究策略。`GeoPFNMix-CatBoost` 则不是对 Lite 的否定，而是对总框架中“全局专家选择”问题的回应：如果全局专家从 RF 升级为 CatBoost，融合框架还能否继续增益？

当 TabPFN 授权打通后，Lite 与 CatBoost 两条线都自然延伸出 TabPFN 先验增强版本。这种演化路径恰恰说明，GeoPFNMix 不是一次性拍脑袋定型的模型，而是一套可渐进扩展的方法族。

## 附录 D：无人值守复现与令牌管理说明

本项目在第二轮修订中专门补齐了无人值守复现链路。原因在于，GeoPFNMix 家族的最终比较已经离不开 `TabPFN`，而 `TabPFN` 的可执行性又同时依赖 Hugging Face 模型访问和 Prior Labs 的头less 授权。如果这两部分不能被脚本稳定识别，那么论文里有关 `PFN` 先验的结论就很难真正复现。

为此，项目在代码中增加了对根目录私有 `token.py` 的导入支持，并将该文件写入 `.gitignore`。这样做的好处是，研究者可以在本地安全保存 `HF_TOKEN` 与 `TABPFN_TOKEN`，而无需把敏感令牌硬编码进仓库。脚本在运行时会先尝试读取本地令牌，再判断当前环境是否具备完整的 `TabPFN` 头less 执行条件；如果条件不满足，GeoPFNMix 的先验分支则安全回退到 `LightGBM`。

需要特别指出的是，由于用户要求文件名固定为 `token.py`，该文件在仓库根目录下可能与 Python 标准库同名模块发生遮蔽。因此，本文建议日常复现以 `python scripts/run_eda.py`、`python scripts/run_baselines.py`、`python scripts/run_geopfnmix.py` 和 `python scripts/run_analysis_assets.py` 这类脚本入口为主，而不是在仓库根目录频繁使用依赖标准库 `token` 的临时命令。这个工程细节虽然不属于算法创新，但它直接关系到论文结论能否在无人值守环境下被稳定复现。
