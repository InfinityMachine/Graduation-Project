# 项目日记

## 2026-04-03

### 决策 1：以地理分组而非随机划分作为主评估协议

- 动机：数据天然带有省-市-县层级结构，随机划分会把同一地区的统计规律泄漏到测试集
- 证据：随机划分最优 RMSE `10.2219`，而按城市分组最优 RMSE `12.5892`
- 结论：主论文结论采用 `GroupKFold(CITY)`，随机划分只保留为补充结果

### 决策 2：移除 `COUNTY` 作为主类别特征

- 动机：`COUNTY` 在该数据中近似一条样本对应一个类别，容易形成“伪地理 ID”
- 目标：减少对局部类别记忆的依赖，提升跨城市泛化
- 结果：模型行为更稳定，线性与树模型不再被县级近唯一标识严重干扰

### 决策 3：保留强基线广覆盖，而不只押单个模型

- 动机：毕业设计需要完整性，必须覆盖线性模型、Bagging、Boosting、可选 foundation model
- 目标：形成可信的论文主结果表，并为创新模型选择合适骨干
- 结果：确认 `RF` 是主协议下最强单模型，`CatBoost` 在随机划分下最强

### 决策 4：TabPFN 只作为文献参考与接口保留，不强行纳入主实验

- 动机：TabPFN 官方流程要求首次授权与令牌配置；当前无头环境缺少 `TABPFN_TOKEN`
- 风险：若硬接入，将使无人值守流程中断
- 结果：代码层面保留接口，实验层面明确记录跳过原因，论文层面作为相关工作与扩展方向讨论

### 决策 5：创新模型从“全量三分支”收敛为“最优可执行子配置”

- 初始设想：全局专家 + 地理残差分支 + PFN/先验专家 + 动态融合
- 实际验证：
  - `CatBoost + HGBT stacker` 过拟合
  - `RF + 残差校正` 有轻微收益
  - `RF + LightGBM + 线性 stacking` 收益最稳定
  - 全模型比简化版没有进一步提升
- 最终选择：将 `GeoPFNMix-Lite` 作为论文中的推荐模型配置

### 决策 6：采用线性 stacking 替代 HGBT 元学习器

- 动机：小样本下 OOF 元特征容易被高容量元学习器过拟合
- 目标：让融合器只学习稳定、低自由度的组合关系
- 结果：融合实验从退化变为稳定提升

### 决策 7：解释性分两层完成

- 第一层：最终模型用 OOF 误差、预测散点、省级 MAE 做结果分析
- 第二层：对最终模型的全局 RF 专家做 SHAP，提取主要因子
- 原因：堆叠异构模型难以直接用单一 SHAP 完整解释，而“整体误差分析 + 主导专家 SHAP”更稳妥

### 决策 8：最终稿中强调“方法筛选过程”而不是“强行保留所有模块”

- 动机：毕业设计的创新不只是提出复杂结构，更重要的是通过消融说明哪些模块真的有效
- 表达策略：
  - 保留 GeoPFNMix 总体框架
  - 将 `GeoPFNMix-Lite` 作为最终部署配置
  - 将残差分支作为受控消融与未来优化方向

### 决策 10：将 `geopfnmix_catboost` 纳入正式消融，而不是只保留早期 RF 系列配置

- 动机：本地快速补测表明，`CatBoost` 作为全局专家时，完整 GeoPFNMix 能稳定优于最强单模型 `CatBoost`
- 结果：
  - `GeoPFNMix-CatBoost` 成为当前最优最终配置
  - `GeoPFNMix-Lite` 继续保留为简洁对照

### 决策 11：图表中的区域标签统一改为英文，降低字体依赖

- 动机：本地图形环境对中文省名标签显示不稳定，影响论文截图质量
- 实施：
  - `province_level_mae.png` 坐标轴省名改为英文
  - 新增分析图表继续统一使用英文轴标签与标题
- 结果：图表在本地与无人值守环境中显示更稳定

### 决策 12：让分析脚本围绕“当前最佳变体”自动出图，而不是硬编码旧模型

- 动机：如果最佳配置变化，手工改图名和数据源容易遗漏
- 实施：
  - `run_analysis_assets.py` 自动读取消融结果并选择最佳 GeoPFNMix 变体
  - 解释性分析自动匹配最佳变体的全局专家
- 结果：论文资产生成流程更稳健，也更适合后续继续迭代
